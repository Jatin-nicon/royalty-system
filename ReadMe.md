# Royalty System  

A web-based system for offline stores to manage and reward customers with credits on purchases.  
This was my first experiment project using **Firebase Authentication** and **Cloud Firestore** for backend services.  

## 🚀 Live Demo  
🔗 [Royalty System on Vercel](https://royalty-system.vercel.app/index.html)  

## 📌 Features  
- 🔐 **Authentication**: Secure login & signup using Firebase Authentication  
- 🧾 **User Profiles**: Each user can view their credit details  
- 💳 **Credits System**: Stores can allocate credits to customers after each purchase  
- 🛡 **Firestore Security Rules**: Database access protected with role-based rules  
- 🎨 **Responsive UI** with HTML, CSS, and JavaScript  

## 🛠 Tech Stack  
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Firebase Authentication, Cloud Firestore  
- **Hosting**: Vercel (previously Firebase Hosting)
